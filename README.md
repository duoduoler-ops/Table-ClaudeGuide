# Claude 使用环境配置指南

把仓库链接发给能操作你电脑的 Agent，告诉它你属于下面哪种情况。Agent 会先检查本机，说明建议改什么、有什么影响。你确认后，它再备份、配置、验证，并告诉你怎么恢复。

## 选你的入口

1. **以前用过 Claude，账号已被封**
2. **从来没用过 Claude**
3. **现在正在使用 Claude**

可以把这句话和仓库链接一起发给 Agent：

> 我属于第 ＿ 种情况。按这个仓库检查我的电脑，先告诉我哪些已经配好、哪些需要处理。等我确认后再改，最后给我验证结果和回退方法。

## 具体会做什么

1. **整理旧环境。** 备份 Claude 配置，按需退出旧登录、移除停用的第三方接口、密钥辅助工具和模型设置。保留历史、项目、Skills、插件和 MCP。只想用 Claude Code 的人，也可以单独卸载桌面端。
2. **检查浏览器和网络。** 在实际使用的浏览器资料里，检查 Claude 网站的网络出口、DNS 解析结果，以及 WebRTC 是否暴露本地 IP。再核对终端出口和系统时间。有问题再修，改完用同一环境复测。
3. **完成登录和隐私设置。** 本人通过官方入口登录，核对账号和登录方式。按自己意愿设置位置权限、模型改进授权和遥测。邮件链接先核对来源，需要时用无痕窗口打开。
4. **安排新账号的使用。** 首次对话可以介绍真实使用背景，按实际任务使用。账号和凭据只由本人保管，不交给反代服务。新账号可先正常使用 3–7 天再决定是否订阅，第一周暂缓进入开发者 Portal。
5. **验证梯子断线保护。** 平时使用梯子的虚拟网卡（TUN）和全局模式。分别检查掉线、切节点、换网络、手动断开、退出、重启六种情况。验收标准是 **Claude 和选定浏览器的新请求，要么经过可用节点，要么失败，不能自动直连**。Agent 按本机能力配置，逐项标明实测、模拟或未测。

## 需要直连国内网站时

先退出 Claude Code，关闭 Claude 网页和相关自动化。保持梯子运行，手动从「全局」切到「直连」即可，无需逐个添加国内网站。直连期间，其他经过梯子的标签页和后台请求也可能使用本地出口。用完后切回「全局」，确认节点已就绪，再打开 Claude。
