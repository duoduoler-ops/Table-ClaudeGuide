# Windows 上的 Claude Code 环境整理与断线保护

如果你以前给 Claude Code 配过第三方 API，现在想查查还有哪些旧设置；或者你担心 Clash 掉线后，Chrome、Edge 和 Claude Code 会悄悄用家里的宽带直连，可以把这个仓库交给你电脑上的 AI 助手。两件事可以单独做，也可以一起做。

| 我想做什么 | 助手会帮我做什么 |
| --- | --- |
| 整理旧的 Claude Code 环境 | 找出旧登录、自定义 API 地址和模型设置，列给你看。你选定要处理的项目后，助手先备份再清理。默认保留对话、项目和浏览器资料。 |
| 防止代理掉线后直连 | 让 Windows 版 Claude Code、Chrome 和 Edge 通过本机 Clash 联网。节点不可用时，这三个程序的新外网连接应当失败。继续用现有浏览器资料和 DNS，仅给选定的程序加防火墙规则。 |

## 怎么用

把**这个仓库的网址**发给能在你 Windows 电脑上运行命令的 AI 助手。想只做一项，就在链接后面写「只整理 Claude 环境」或「只做断线保护」。如果助手只是总结网页，把下面这句话也发给它。

> 按仓库里的执行指南检查我的电脑。先告诉我发现了什么、建议改哪里。等我确认后，先备份再动手，最后告诉我哪些情况测过、怎么恢复。

**给收到链接的 Agent**　打开[本机执行指南](./AGENT-GUIDE.md)，从第 1 步只读检查开始。用户点名一项就只查那一项；只发链接时，先列出两项的本机情况供用户选择。

## 配好以后，国内网站还能直连吗？

可以。比如你要用 Chrome 去 B 站发视频，先退出 Claude Code，关闭 Claude 网页及相关自动化。保持 Clash 的虚拟网卡（TUN）开启，把右侧的「全局」切到「直连」，再重新打开投稿页。发完切回「全局」，确认选中了节点，再开 Claude。无需逐个添加国内网站。手选直连期间，其他经过 Clash 的标签页和后台请求也可能走本地出口。

## 这套配置实际测过什么？

一台 Windows 11 家庭版电脑上，三个程序尝试绕过代理时均被拦住。切到故障节点时，Chrome 和 Edge 的新请求失败；手选直连后，Edge 能打开 B 站公开页面。代理入口停止用未监听端口模拟，Windows 冷启动和 Wi-Fi 切手机热点尚未实测。完整记录见[本机案例](./AGENT-GUIDE.md#case)。
