# Claude 使用环境配置指南

![Table-ClaudeGuide：黑蛋和 Claude 一起翻看指南](assets/table-claudeguide-banner.png)

把仓库链接发给能操作你电脑的 Agent，说「跑一下环境设置」就可以。**第一轮只检查环境，不需要先安装 Claude、注册账号或登录。** Agent 按[执行指南](./AGENT-GUIDE.md)用现有浏览器、终端和无需登录的公开测试页做检查，先把结果给你。如果 Agent 只能操作云端，由你在自己的浏览器打开检测页，把读数或打码截图交给它。需要改设置时，等你确认后再备份、修改和复测。

## 选你的入口

1. [**以前用过 Claude，账号已被封**](./AGENT-GUIDE.md#route-1)
2. [**从来没用过 Claude**](./AGENT-GUIDE.md#route-2)
3. [**现在正在使用 Claude**](./AGENT-GUIDE.md#route-3)

可以把这句话和仓库链接一起发给 Agent：

> 我属于第 ＿ 种情况。按这个仓库检查我的电脑，先告诉我哪些已经配好、哪些需要处理。等我确认后再改，最后给我验证结果和回退方法。

## 具体会做什么

1. **先查当前环境。** 在平时用的浏览器里打开 IPPure，查两个 Claude 域名的出口、WebRTC 和 DNS，分别报告 Claude 页的环境分和 IPPure 首页的出口 IP 风险系数。**环境分超过 30，Agent 主动看评分明细，逐项说明命中了什么、哪些需要处理以及理由。** 只看到总分，就请你补一张明细截图，不猜原因。需要改设置时，先让你确认，改完再用同一浏览器资料复测。终端出口和系统时间也单独核对。全程无需安装或登录 Claude。[Claude 环境检测](https://ippure.com/claude) · [IP 纯净度](https://ippure.com/) · [逐项检查表](./AGENT-GUIDE.md#network-check)
2. **按需修复，再用公开页面复测。** 如果有旧配置，只处理你选定的旧登录、第三方接口或模型设置，保留历史、项目、Skills、插件和 MCP。需要断线保护时，先验证现有浏览器在正常节点能上网、代理不可用时新连接会失败。只做环境设置，到这里就可以结束。
3. **要使用 Claude 时再选入口。** 网页版只需浏览器。需要 Claude Code 或桌面端时，经你同意再安装，安装后先核实该程序的代理和断线表现。最后由你决定是否注册或登录，以及怎样设置位置权限、模型改进授权和遥测。邮件链接先核对来源，需要时用无痕窗口打开。账号已暂停时，保留原账号走[官方申诉](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals)。
4. **安排新账号的使用。** 首次对话可以介绍真实使用背景，按实际任务使用。账号和凭据只由本人保管，不交给反代服务。新账号可先正常使用 3–7 天再决定是否订阅，第一周暂缓进入开发者 Portal。

### 断线保护怎样算通过

第 2 步选择了断线保护，就在配置阶段验证。平时使用梯子的虚拟网卡（TUN）和全局模式。分别检查掉线、切节点、换网络、手动断开、退出、重启六种情况。验收标准是 **受保护程序的新请求，要么经过可用节点，要么失败，不能自动直连**。Agent 按本机能力逐项标明实测、模拟或未测。

## 需要直连国内网站时

先退出 Claude Code，关闭 Claude 网页和相关自动化。保持梯子运行，手动从「全局」切到「直连」即可，无需逐个添加国内网站。直连期间，其他经过梯子的标签页和后台请求也可能使用本地出口。用完后切回「全局」，确认节点已就绪，再打开 Claude。
